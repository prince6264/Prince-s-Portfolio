PRINCE PANDEY — PORTFOLIO WEBSITE

Files:
- index.html: the complete responsive portfolio website.

Before publishing:
1. Open index.html and replace YOUR_EMAIL@example.com.
2. Replace YOUR-LINKEDIN and YOUR-GITHUB with your real profile URLs.
3. Add your degree, college, graduation year, and any verified experience.
4. Add screenshots and verified findings for the Online Retail Data Analysis project.

To publish free:
- GitHub Pages: create a public GitHub repository, upload index.html, then enable Pages in the repository Settings.
- Netlify: sign in, then drag the folder containing index.html into Netlify Drop.

This package creates the website files; it does not publish a public URL automatically.
